1. Photo folders

Source files are strictly read-only. Edits save to .hdrtoys/

    2. Tailscale

    The library joins your tailnet as its own device
    1. Create an auth key at Tailscale → Settings → Keys. Leave Ephemeral off. If device approval is on, turn on Pre-approved.
    2. Turn on MagicDNS and HTTPS Certificates in DNS settings.
    3. Paste the key and connect. It is used once to join and is not saved.

    We try to keep cloudedits secure, but it's only as secure as your Tailscale setup and is written using AI tools, so use it with caution.
